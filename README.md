# 🐾 宠迹 PawTrace — 养宠成长记录与社区

一站式记录宠物成长、管理健康档案、同城交友的宠物社区产品。纯前端实现，数据本地持久化（localStorage），可部署于 GitHub Pages。

## ✨ 核心功能

| 模块 | 说明 |
|---|---|
| 🏠 首页 | 宠物档案卡片、健康数据概览、智能到期提醒、同城动态流 |
| 💉 健康档案 | 体重趋势图（SVG 交互图表）、疫苗 / 驱虫记录、下次到期自动计算 |
| ⏱️ 成长时间线 | 自动串联出生、体重、疫苗、驱虫、周岁等里程碑 |
| 🧭 同城宠友 | 按地域 + 物种 + 品种匹配度排序，同城优先，可关注 / 打招呼 |
| 🐾 养宠日常 | 图文动态发布、点赞、评论、分享 |

## 🚀 技术栈

- 原生 HTML / CSS / JavaScript，零构建依赖
- localStorage 持久化 + 预置演示数据
- 手写 SVG 交互式折线图（含 hover 十字线 + 数据提示）
- 响应式设计（桌面 / 移动端底部导航）

## 📁 结构

```
pawtrace/
├── index.html      # 页面骨架
├── styles.css      # 设计系统与全部样式
├── app.js          # 数据层 / 渲染 / 交互 / 图表
└── .github/workflows/deploy.yml  # GitHub Pages 自动部署
```
